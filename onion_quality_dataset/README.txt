Onion Quality Grader - prototype image dataset

Classes used for the first MVP:
- good: whole onions with no obvious visible rot/mold
- bad: onions with visible rot, mold, or severe damage

IMPORTANT:
This is a tiny prototype dataset assembled from the images uploaded in the chat and the 5-image Bad Onion ZIP. It is NOT large enough for a reliable production CNN. It is suitable only for demonstrating the end-to-end hackathon concept.

The excluded_from_training folder contains images that were not used because they are cut onions, mixed/ambiguous scenes, or otherwise unsuitable for a clean good/bad training label.
